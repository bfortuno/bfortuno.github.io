# bfortuno.github.io

Personal academic website for Benjamin I. Fortuno, built with [Astro](https://astro.build) and deployed to GitHub Pages via GitHub Actions.

Built as a sequence of [OpenSpec](https://github.com/Fission-AI/OpenSpec) changes — see `openspec/`.

## Commands

- `npm install` — install dependencies
- `npm run dev` — start local dev server at `localhost:4321`
- `npm run build` — build the production site to `./dist/`
- `npm run preview` — preview the production build locally
